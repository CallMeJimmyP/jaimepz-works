# Jaime's Portfolio Website

A simple, responsive portfolio website built with HTML, CSS, and JavaScript.

## Overview

This project contains a modern personal portfolio landing page with:

- a clean hero section
- an about section and skill list
- a project showcase grid
- a contact section
- a responsive layout for mobile and desktop

## Files

- `index.html` – page structure
- `styles.css` – design and responsive layout
- `script.js` – lightweight navigation behavior

## Running locally

Open `index.html` directly in a browser, or serve the folder with a local web server:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Customize

Update the text in `index.html` to add your own name, bio, project titles, and contact links.

## GitHub Pages

This repository is set up for GitHub Pages, so the site can be published through the GitHub Pages settings in the repository.
